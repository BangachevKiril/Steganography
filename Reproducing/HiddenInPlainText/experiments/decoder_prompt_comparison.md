# Frozen decoder prompt comparison

Compare four new decoder system prompts against the completed original-prompt control from `decoder_comparison_step40_20260929T222013Z`. Use the same 32 saved validation-step40 answers of the revised PIQA run, unchanged public strings, participant identities, and true bits for scoring only. No answer or judge generation and no parameter updates are performed. The ongoing RL allocation and settings remain unchanged.

The four variants are original_plus_prior, concise, concise_plus_prior, and concise_plus_prior_uncertainty. The concise conditions retain each decoder role, its correct-guess reward, available inputs, private thinking budget and exact binary output requirement, while removing sender-role instructions and extended scoring descriptions. Prior information states that the bit is uniform and independent of the public string. Uncertainty guidance says neither bit is a default. No external balancing, label manipulation or sampling intervention is applied.

For each prompt, decode each answer under both vanilla Qwen3-4B and frozen checkpoint40 A/B/I adapters, for receiver and interceptor, with eight independent private-thinking replicates. Initial sampling seeds match the original control and every prompt/model condition. This is 4,096 new decodes, plus 1,024 reused control decodes, across only 32 answer contexts. The receiver uses the opposite communicator adapter; interceptor uses I. Preserve T=256, temperature 0.6, binary constrained output and generation batch size 16. Matched seeds do not imply identical reasoning or guarantee bitwise accelerator arithmetic across differing prompt lengths.

The reused control must pass config/source/input hash, checkpoint identity, prompt, selection, model verification and completion checks. Record immutable provenance in MANIFEST.json and mark every row as reused control or new inference. All parameters stay frozen, all models stay in evaluation mode, and no optimizers are created. Private reasoning text and token sequences are never saved or displayed.

Report per prompt/role/model: mean conditional final-token P(0), sampled zero count, correct count, mean probability assigned to the true bit, results by true bit and receiver identity, cutoff counts, and how many of the 32 eight-replicate groups contain both guesses. Compare each variant against the original control with paired answer-level differences; compare trained and vanilla arms separately. A reduction in zero bias or increase in guess variation is not evidence of successful decoding. The 32 trained-sender answer contexts limit generalization. No control is regenerated, and no answer is filtered out of the main comparison.

Run in a separate preemptable H100 allocation. Atomic committed batches and an exclusive run lock permit resumption after preemption. Preserve public config, prompts, selection, manifest, model verification, results, per-question CSV and report in a separate results directory.
